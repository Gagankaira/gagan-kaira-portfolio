# Gagan Kaira — Senior Data Engineer Portfolio

A production-quality personal portfolio built with Next.js 16, TypeScript, Tailwind CSS, Framer Motion, and a static GitHub Pages deployment.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is generated in `out/`.

## GitHub Pages

The included GitHub Actions workflow builds the static export and deploys it to GitHub Pages.

For this repository, the expected URL is:
`https://gagankaira.github.io/gagan-kaira-portfolio/`

## Portfolio content

All resume and project content is centralized in `data/portfolio.ts`.
